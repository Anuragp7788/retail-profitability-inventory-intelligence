# Project plan

## Milestones

1. **Repository and source setup** — project documentation, sources and local environment.
2. **Data discovery** — download files, inspect schemas, grain, date ranges, duplicates, missingness and key quality.
3. **Python preparation** — build repeatable, tested cleaning and profiling steps.
4. **PostgreSQL modelling** — design source/staging/analytics tables and documented relationships.
5. **SQL analysis** — sales, profitability, discount, product, store and inventory questions.
6. **Excel validation** — independent totals and KPI reconciliation.
7. **Power BI** — star-schema model, DAX measures, executive page and drilldowns.
8. **Business report** — findings, recommendations, caveats and portfolio screenshots.

## Working agreement

For each milestone:
- Build the artefact.
- Explain the technique and business reason.
- Validate output against source data and expected behavior.
- Record limitations and update this checklist only when completed.
