# Data directory

## Folder conventions

- `raw/`: original downloaded files. Do not edit them.
- `processed/`: validated outputs generated by notebooks. Rebuild them from raw inputs.

## Sources

1. [Sample Superstore (Kaggle)](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
   - Planned use: order, product, customer, discount, sales and profit analysis.
   - Download manually from the source page. Check the dataset-specific licence and redistribution terms before sharing the file.

2. [Retail data — Mendeley Data](https://data.mendeley.com/datasets/27x8mjm8k4/1)
   - Planned use: daily store/SKU sales and on-hand inventory analysis.
   - Review the exact files, data dictionary, version and CC BY 4.0 attribution requirements on the landing page before using or redistributing.

## Data governance rules

- Keep original source files unchanged.
- Record the download date, version, filename, source URL and licence in the data inventory.
- Never infer missing values without documenting the rule.
- Do not assume two datasets share the same product/store keys.
- Do not commit raw files until redistribution rights are confirmed.
- Do not publish any private or personal information.

A data inventory will be added after the first local download and inspection.
